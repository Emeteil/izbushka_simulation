# Izbushka Simulation

Цифровой двойник робота «Избушка», реализованный на движке **Unity3D** (C#) для отладки систем и алгоритмов без физического оборудования.

## Назначение

Симуляция обеспечивает виртуальное физическое окружение для тестирования:
- Логики передвижения и навигации.
- Протоколов передачи данных.
- Визуализации эмоций и анимации в реальном времени.

## Функциональные возможности

1.  **Обмен данными (VirtualLink)**: Подключение к [izbushka-web-core](https://github.com/Emeteil/izbushka-web-core) по протоколу TCP (порт 5470). Обмен пакетами происходит в формате JSON.
2.  **Эмуляция сенсорного уровня**: Передача данных с виртуальных датчиков (гироскоп, лазерные дальномеры на базе Raycast).
3.  **Виртуальная камера**: Трансляция кадрового потока из Unity в [izbushka-web-core](https://github.com/Emeteil/izbushka-web-core). Используется в качестве основного источника изображения при отсутствии подключения реального робота.
4.  **Управление**: Полная поддержка команд движения, транслируемых через транспортную шину `web-core`.

## Системная интеграция

Симуляция работает в качестве TCP-клиента. Перед запуском симуляции необходимо убедиться, что сервер [izbushka-web-core](https://github.com/Emeteil/izbushka-web-core) активен и готов к приему соединений на порту 5470.
